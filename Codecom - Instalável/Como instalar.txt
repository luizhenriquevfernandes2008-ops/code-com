NO PC DE CADA AMIGO
1. Confirme que o notebook anfitriao esta ligado com o servidor aberto.
2. Clique duas vezes em "Instalar Code com.bat". Ele abre o link fixo do app.
3. No Edge ou Chrome, clique em "Instalar Code com" na tela de login.
4. Depois, use o atalho "Code com" criado no Desktop ou menu Iniciar.
