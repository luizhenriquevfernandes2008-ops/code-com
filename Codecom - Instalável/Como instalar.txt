NO NOTEBOOK ANFITRIAO
1. Mantenha o projeto completo e o Tailscale conectados neste notebook.
2. Clique duas vezes em "Abrir Code com.bat". Ele inicia o servidor online.
3. Deixe a janela do servidor aberta enquanto os amigos usarem o app.

NO PC DE CADA AMIGO
1. Confirme que o notebook anfitriao esta ligado com o servidor aberto.
2. Clique duas vezes em "Instalar Code com.bat". Ele cria o atalho "Code com"
   na Area de Trabalho e abre o link no Opera instalado (Opera ou Opera GX).
3. Depois, use o atalho "Code com" para abrir o app no Opera.

"Instalar Code com.bat" e para o cliente: cria o atalho e abre o site, mas nao
inicia servidor. O amigo nao precisa de Python, Tailscale nem dos arquivos do
projeto. O app continua funcionando em uma aba normal do Opera.

O Opera pode nao mostrar uma opcao de instalacao PWA nesta versao. O atalho
criado pelo instalador permite abrir o Code com diretamente pelo Opera.

Se houver um atalho antigo de um link temporario, remova-o e execute o
instalador novamente para recriar o atalho com o link fixo.
